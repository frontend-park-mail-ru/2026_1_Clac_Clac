# CSP: Добавить nexus-support-prod в img-src

## Проблема

CSP-заголовок на сервере не разрешает загрузку изображений с домена `nexus-support-prod.hb.ru-msk.vkcloud-storage.ru`, на котором хранятся вложения обращений (appeals).

Ошибка:
```
Loading the image 'https://nexus-support-prod.hb.ru-msk.vkcloud-storage.ru/attachments/...' 
violates the following Content Security Policy directive: 
"img-src 'self' data: 
 https://nexus-avatars-prod.hb.ru-msk.vkcloud-storage.ru 
 https://nexus-boards-prod.hb.ru-msk.vkcloud-storage.ru 
 https://nexus-cards-prod.hb.ru-msk.vkcloud-storage.ru 
 https://nexus-appeals-prod.hb.ru-msk.vkcloud-storage.ru"
```

## Решение (на стороне бэкенда)

Добавить в CSP-заголовок (секция `img-src`) домен:
```
https://nexus-support-prod.hb.ru-msk.vkcloud-storage.ru
```

Также вероятно нужно добавить его в `connect-src` для загрузки вложений через `fetch`/`XMLHttpRequest`.

## Где менять

CSP задаётся на уровне серверной инфраструктуры (nginx, CloudFront, балансировщик). Со стороны фронтенда изменений не требуется.

## Фронтенд-подтверждение

В `src/templates/support_widget.hbs:131` изображение вложения рендерится корректно:
```hbs
<img src="{{currentTicket.attachment_url}}" class="sw-msg-img" alt="Вложение">
```

Код загрузки вложения в `src/modules/supportWidget/index.ts:61-64` тоже корректен — файл отправляется через `FormData` PUT-запросом на `/appeals/:link/attachment`.

# Валидация: max_tasks > 0 и ≤ 200

## Текущее поведение

При создании/редактировании колонки поле «Максимальное число задач»:
- Пустое → подставляется 100
- `isNaN` → подставляется 100
- `=== 0` → подставляется 100 (молча)
- `< 0` → ошибка: «Лимит задач не может быть отрицательным»
- `> 200` → ошибка: «Лимит задач не может быть больше 200»

## Требуемое поведение

- Пустое → подставляется 100 (без изменений)
- `isNaN` → подставляется 100 (без изменений, т.к. с новым `replace(/\D/g, "")` уже не может быть NaN)
- `<= 0` → ошибка toast: «Число задач должно быть больше 0»
- `> 200` → ошибка toast: «Число задач должно быть не больше 200»

## Файлы для изменений

### 1. `src/modules/kanban/components/KanbanColumnManager.ts:79-91`

Заменить:
```
if (maxVal === "")            → max = 100
isNaN(max)                    → max = 100
max === 0                     → max = 100
max < 0                       → Toast.error("Лимит задач не может быть отрицательным")
max > 200                     → Toast.error("Лимит задач не может быть больше 200")
```

На:
```
maxVal === ""  → max = 100
isNaN(max)     → max = 100
max <= 0       → Toast.error("Число задач должно быть больше 0"); return
max > 200      → Toast.error("Число задач должно быть не больше 200"); return
```
